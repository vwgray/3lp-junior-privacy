# 3LP Junior — Privacy Policy

The published privacy policy for **3LP Junior: Brick by Brick**, an iOS app.

Live at **https://vwgray.github.io/3lp-junior-privacy/**

Apple requires a publicly reachable privacy policy URL for every App Store
listing, and the Kids Category requires one without exception. That is the only
reason this repository is public and separate: the app's own repository is
private and stays that way, and GitHub Pages will not serve from a private
repository on a free plan.

Nothing here is part of the app. It is one static HTML file with no scripts, no
tracking and no external requests — which would be an odd thing for a privacy
policy to carry.

## Editing it

`index.html` is the whole site. Change it, commit, push; GitHub Pages
redeploys within a minute or so.

If the policy changes in a way that affects what the app does, update the
"Last updated" date at the top as well. Apple reads this page during review,
and the date is what tells a reviewer the page is maintained.
